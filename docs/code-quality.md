# 代码质量整理记录

## 已修正

| 问题 | 处理 |
| --- | --- |
| 文案散落在页面 JSX、全局客户端组件中 | 按页面和用途提取到 `content/`，保留原来的换行、版式和手记内容 |
| QQ、奖励金额、奖励政策重复维护 | `content/site.ts` 作为共享事实来源，正文、SEO、FAQ、弹窗和复制操作引用它 |
| 角色标签与角色概述分离 | 名称、长标签、短标签和英文标签集中在 `content/characters.ts`，标签从角色名组合 |
| SEO、导航名称难以一起检查 | 页面 SEO 与正文放在同一文案文件，SEO 标题默认引用导航名称，H1 独立编辑 |
| `roadside.tsx` 混合全站框架、长篇角色内容、照片和联系功能 | 拆成 `site-shell.tsx`、`photos.tsx`、`story-scenes.tsx`、`contact.tsx`，缩小模块职责 |
| 动效组件不能通过 ESLint | 玻璃滑块通过自己持有的 DOM 引用定位父轨道，移除对传入 ref 的依赖；保留 Hook 检查规则 |
| 标签选项依赖被 ESLint 注释忽略 | 将固定选项定义在组件外，加入真实依赖，并在类型上要求至少一个选项 |
| 滑块只观察整体轨道尺寸 | 同时观察标签尺寸，文字宽度改变后重新定位；无匹配导航项时取消残留动画并清除就绪状态 |
| 弹窗由原生链接开启，缺少显式焦点返回 | 关闭照片和联系弹窗后，将焦点还给原入口；保留未加载 JS 时的链接回退 |
| 复制状态可能与新值不一致、回退清理不足 | 反馈绑定被复制的值，阻止重复并发复制，旧浏览器回退使用 finally 清理临时输入框并恢复焦点 |
| iOS 弹性滚动可能让阅读进度越界 | 将进度限制在 0–100% |
| 残留 CSS 与无用节点 | 删除 `.welcome h1>span`、旧 `.thought-list`、`.draft-label`、`.meaning-quote`、`.dialog-footnote`、`.full-width`、`.button-light`、未使用的标题 span 样式；移除始终隐藏的 `.stage-note` 与相关断点规则 |
| 被新动画覆盖的旧代码 | 移除 `page-enter` 类、关键帧及覆盖规则，继续由现有 Web Animations 实现切换 |
| 自托管源码含未接入的服务端模板 | 删除空数据库结构、数据库示例、登录辅助、Vite/Cloudflare 配置和相关旧脚本；UI 目录保留实际使用的 4 个文件 |
| 依赖包含已移除模板与组件所需包 | 运行依赖从 24 项减到 8 项，开发依赖从 18 项减到 9 项；同步裁剪锁文件，仅保留可达依赖，不升级版本、不更改完整性校验值 |
| 默认开发命令不符合交付用途 | `pnpm dev` 使用标准 Next.js；保留旧 `dev:selfhost` 命令作为兼容别名 |
| 子目录路径容易在修改后退化 | 构建后自动运行 `scripts/verify-export.mjs`，检查五个 HTML 的本地资源、页面链接、srcSet 与锚点 |

## 保留的合理设计

- 没有添加数据库或 CMS。对这类静态展示网站，文案文件更直接；修改后仍需构建和上传。
- 页面主标题、导航名和 SEO 标题有不同用途，不强制显示同一句话。
- 保留实际使用的 Radix/shadcn 基础组件及其通用 API，未为了删除所有未调用导出而改写第三方组件。
- 本地 WebP 使用原生 `img`、明确尺寸、srcSet 和懒加载，因此仅在两个相关文件中说明并关闭 Next 的图片组件建议规则，其余应用检查保持开启。
- 不把动态类名、媒体查询、不支持特效时的回退或原生无 JS 链接误判为死代码。

## 范围与限制

这是当前源码的维护性、静态检查、交互与部署路径审查，不是渗透测试或第三方依赖漏洞审计。检查结果见 `verification.md`。
