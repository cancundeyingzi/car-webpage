## 替换两侧照片

现有手机照片包含底部白色相机边框。`Photo` 组件及 `.photo-ink` 样式使用容器裁切隐藏该边框，因此不能只盲目替换为任意比例图片。

如果继续使用相近比例且带同类边框的照片，生成 768 和 1536 两种宽度的 WebP，替换同名文件后检查首页与照片弹窗。

如果换成干净的无边框照片（推荐），先裁成 4:3，在 `components/photos.tsx` 的 `Photo` 组件更新图片 width/height，并在 `app/globals.css` 的最后添加或调整：

```css
.photo-ink img,
.night-card .photo-ink img,
.visit-photo .photo-ink img {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
}
```

再根据角色在画面中的位置微调 `object-position`。如果照片以完整侧面为主，不要把角色脸部裁掉；弹窗宜显示完整画面。车头图最好使用接近 3:2 的画幅，宽 1536 像素左右即可。

## 只需准备这几张

1. 主驾驶侧正侧面一张：完整展现紫色自设、木船和火球。
2. 副驾驶侧正侧面一张：完整展现祈夙与画布。
3. 车头或引擎盖一张：能看清踏水、牵引画布的动作。
4. 可选的两三个细节：火球、纸张边缘、接缝或你最想优化的局部。

不需要为了网站专门拍车尾全景或斜向整车照，也不需要贴膜 3D 模型。网站用两侧对照、局部特写和轻视差表达立体感。尾部寓意已通过文字解释；想征求该处修改意见时，可另外准备清楚的局部标注图，通过 QQ 讨论。

拍摄时尽量保持两侧光线与机位高度接近，避开强烈反光，留出车身前后边缘。首页用横图，手机中可按主体裁切。
